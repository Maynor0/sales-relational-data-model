# SQL - Base 3

En esta etapa, la base limpia se dividió en varios archivos CSV para representar las tablas del modelo.

Posteriormente, en SQL se reconstruyó la estructura relacional mediante tablas para:
- vendedores;
- sedes;
- canales;
- facturas;
- vehículos;
- presupuesto.

El script incluye:
- creación de tablas;
- carga de datos;
- consultas con JOIN;
- resúmenes con COUNT, SUM, AVG, MAX y MIN;
- análisis temporal;
- funciones de ventana como OVER() y RANK().
