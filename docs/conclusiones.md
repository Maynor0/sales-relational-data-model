# Conclusiones

## Resultado general
La base permitió construir un flujo completo de trabajo orientado a análisis de datos y business intelligence, partiendo desde una base original amplia hasta llegar a un modelo relacional funcional y visualizable.

## Principales logros del proyecto
A lo largo del proyecto se consiguió:

- limpiar y reorganizar la base original en Excel;
- separar la información en 6 tablas relacionadas;
- estructurar cada tabla en Power Query para su uso analítico;
- reconstruir el modelo en SQL a partir de archivos CSV;
- desarrollar un modelo relacional y visualizaciones en Power BI.

## Valor analítico del proyecto
La estructura final permitió analizar el negocio desde varios ángulos:

- desempeño de ventas por sede;
- comparación entre ventas y presupuesto;
- análisis por canal;
- análisis por marca y tipo de vehículo;
- desempeño por vendedor;
- métricas de costo, margen, ticket promedio y participación de ventas.

## Aporte de cada herramienta
Cada herramienta cumplió una función específica dentro del flujo:

- Excel: limpieza inicial, corrección y organización por hojas;
- Power Query: preparación estructurada de tablas;
- SQL: reconstrucción del modelo relacional y consultas analíticas;
- Power BI: modelado final, medidas y visualización de resultados.

## Aprendizajes demostrados
Este proyecto no solo muestra visualización de datos, sino también capacidades de preparación y modelado.  
Demuestra limpieza de datos, organización relacional, validación de estructura, análisis de negocio y construcción de dashboards.

## Cierre
La base 3 puede presentarse como uno de los proyectos más completos del portafolio, porque integra varias herramientas dentro de un mismo flujo de trabajo y convierte una base compleja en un modelo analítico reutilizable.
